# Описание проекта

## Русский

**GitHab Installer** — это современное десктопное приложение для автоматизации установки Git-проектов. Поддерживает GitHub, GitLab, Bitbucket и SSH. Автоматически определяет тип проекта и устанавливает зависимости (Node.js, Python, .NET, Java, Go, Rust, Ruby, Docker, CMake). Безопасное хранение токенов через Windows DPAPI. Кроссплатформенная сборка для Windows, macOS и Linux.

**Ключевые особенности:**
- 🌐 Поддержка GitHub, GitLab, Bitbucket, SSH
- 🔐 Безопасное хранение токенов (Windows DPAPI)
- 🔍 Автоматическое определение типа проекта
- 📦 Установка зависимостей для 10+ языков
- 🎨 Современный интерфейс WPF
- 🔄 CI/CD через GitHub Actions
- 🧪 Покрыто unit-тестами

## English

**GitHab Installer** is a modern desktop application for automating Git project installation. Supports GitHub, GitLab, Bitbucket, and SSH. Automatically detects project type and installs dependencies (Node.js, Python, .NET, Java, Go, Rust, Ruby, Docker, CMake). Secure token storage with Windows DPAPI. Cross-platform build for Windows, macOS, and Linux.

**Key Features:**
- 🌐 GitHub, GitLab, Bitbucket, SSH support
- 🔐 Secure token storage (Windows DPAPI)
- 🔍 Automatic project type detection
- 📦 Dependency installation for 10+ languages
- 🎨 Modern WPF interface
- 🔄 GitHub Actions CI/CD
- 🧪 Unit test coverage
